📊 日志系统演示

展示 Rock Framework 强大的日志功能

🎯
多级别日志
支持 Debug、Info、 Warn、Error、 Fatal 五个级别
🔄
动态级别控制
运行时可动态调整日志级别，SetLevel() 方法灵活控制
📝
格式化输出
支持 Printf 风格格式化， 同时提供 Println 便捷方法
📊
请求日志
自动记录HTTP请求信息，包括 方法、 路径、状态码 等
🎛️
灵活配置
支持 多输出、级别过滤、 输出重定向 等配置
🔗
Context集成
与 Context 深度集成， 可在请求上下文中直接使用日志方法

📋 使用示例

基本日志记录

rock.Debug("这是调试信息") rock.Info("这是一般信息") rock.Warn("这是警告信息") rock.Error("这是错误信息")

格式化日志

rock.Infof("用户 %s 在 %s 登录", username, time.Now()) rock.Debugf("处理请求 %s，耗时 %v", requestID, duration)

Context日志

c.LogDebug("开始处理请求") c.LogInfo("参数验证通过") c.LogError("数据库连接失败: %v", err)

请求日志

logger := app.Logger() logger.EnableRequestLog(true) // 自动记录所有HTTP请求

日志级别

DEBUG 最详细的调试信息
INFO 一般性信息记录
WARN 警告信息
ERROR 错误信息
FATAL 致命错误

⚙️ 配置选项

设置日志级别

app.SetLogLevel(rock.LevelDebug) // 设置为调试级别

输出重定向

file, _ := os.Create("app.log") app.SetLoggerOutput(file) // 输出到文件

启用请求日志

app.EnableRequestLog(true) // 启用HTTP请求日志

多输出目标

logger := app.Logger() logger.AddOutput(os.Stdout) // 控制台 logger.AddOutput(file) // 文件 logger.AddOutput(networkWriter) // 网络
